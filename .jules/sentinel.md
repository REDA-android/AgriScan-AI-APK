## 2024-05-24 - DOM-based XSS in Global Error Handlers
**Vulnerability:** The global error handlers (`window.onerror` and `window.addEventListener('unhandledrejection')`) in `src/main.tsx` were using `innerHTML` to display error messages. This could lead to a DOM-based Cross-Site Scripting (XSS) vulnerability if the error message or reason contained unsanitized user input. Additionally, the handlers were exposing the error stack traces, which can leak internal application paths and logic to users.
**Learning:** Even internal diagnostic or global error handlers that are not intended to display user content can be vectors for XSS if an attacker can manipulate the error message. Exposing stack traces is also a security risk as it reveals implementation details.
**Prevention:** Always use safe DOM manipulation methods like `document.createElement()`, `innerText`, and `appendChild()` instead of `innerHTML`. Never expose stack traces in the UI or production environments. Fail securely by showing a generic error message and logging the details securely.
