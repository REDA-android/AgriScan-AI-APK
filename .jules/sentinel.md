## 2024-05-24 - [DOM-based XSS in Global Error Handlers]
**Vulnerability:** Found insecure `innerHTML` assignments in global error handlers (`window.onerror` and `unhandledrejection` events) within `src/main.tsx`. The code concatenated potentially unsanitized inputs like `error.stack`, `message`, and `event.reason` directly into the DOM using `innerHTML`. This could have allowed an attacker to execute arbitrary scripts if they could influence the error message content.
**Learning:** Even diagnostic or debugging code (like crash overlays) must use secure DOM APIs (`document.createElement`, `innerText`, `appendChild`) rather than string concatenation with `innerHTML` when displaying dynamically generated data, especially errors and stack traces that might reflect unsanitized input.
**Prevention:** Avoid `innerHTML` entirely when displaying user-influenced or dynamically generated content. Always prefer standard DOM manipulation methods or React's built-in JSX escaping.
